# STM32 环境监控系统硬件 V1.2（国产贴片版，板载电源）

主控是**立创·地阔星 STM32F103C8T6 开发板**（LCKFB-DKX-STM32F103C8T6，立创编号 C22396880），插在板上的两排 1×20P 排母（J1/J2）里。开发板 53.34 × 22.86 mm，40 个引脚的顺序和 Blue Pill 相同。

温湿度、时钟、光照、12V→5V 降压都做在板上，只需外接 OLED 模块、12V 适配器和灯带。

## 已修正的严重错误：J2 排母方向

V1.0 和 V1.1 的 J2 排母封装转了 180°，它的 1 号脚（3V3）和 J1 的 1 号脚（BAT）不在同一端。但开发板实物上，BAT 和 3V3 在同一端。按旧版打板，开发板插上后 J2 这一排会全部错位：
- 板上的 3V3、GND、5V 会接到 PB12、PB13、PB14
- 真正的电源脚悬空
- I²C、PA8、PA11 也会接错

V1.2 已把 J2 转回和 J1 同向，两排焊盘已逐个对照立创·地阔星的官方引脚图核对过。

### V1.2 板载降压电路

按 XL1509 数据手册（Rev 2.1）的 12V→5V 参考电路设计：

| 位号 | 器件 | 说明 |
| --- | --- | --- |
| U3 | XL1509-5.0E1（芯龙，C61063） | 150 kHz 降压芯片，最大 2A；ON/OFF 脚接地，常开 |
| L1 | SWPA8040S680MT（顺络，68µH，额定 1.25A，C36418） | 与手册推荐的 68µH 一致 |
| D2 | SS34（辰达，3A 40V 肖特基，C8678） | 手册用的是 1N5820，SS34 是贴片的同类管 |
| C5 | 470µF 35V 贴片电解（科尼盛，C5155332） | 输出电容，和手册一致 |
| C7 | 470µF 35V 贴片电解（同上） | 输入电容，手册要求 ≥180µF |
| C6 | 1µF 50V 0805（火炬，C141772） | 输入高频旁路 |

全板 5V 负载估计不到 300 mA，远低于 XL1509 和电感的额定值。

## 下载程序

**开发板的 Type-C 口不能直接下载程序。** 立创官方手册列出的下载方式只有 DAP-Link、ST-Link 和串口烧录；板上没有 USB 转串口芯片，STM32F103 本身也不支持 USB 下载。Type-C 只用来供电，或以后做 USB 通信。

下载程序时，用 DAP-Link（有国产的）或 ST-Link 接开发板自带的 4 针 SWD 口（3V3、DIO、CLK、GND）。开发板插在 J1/J2 上时，这个口仍露在外面。

## 装配和使用注意事项

1. **SD3077 已对照数据手册核对。** 依据兴威帆《SD3077 datasheet v4.0》：SOP8（208mil），1、2 脚 NC，3 VBAT，4 GND，5 SDA，6 SCL，7 INT，8 VDD，与工程连线、焊盘编号一致；7 位 I²C 地址 0x32（0110010，写 0x64/读 0x65）。使用 CR1220 一次性电池，**程序里不要写 0x18 寄存器 = 0x82（开启 VBAT 充电）**；它的驱动与 DS3231（0x68）不通用。
2. **U1 用 GXHT30C，不是 GXHT30。** 原来选的 GXHT30（C3010791）在立创商城已停售，换成同封装的 GXHT30C（C2913569，有现货）。两颗的 9 个引脚名称和编号一致，封装同为 DFN-8 2.5×2.5，PCB 不用改。它和 SHT30 引脚、协议兼容，可以直接用 SHT30 的驱动。
3. **12V 适配器**要选 5.5×2.1 mm 圆口、中心正极的。
4. **开发板的 Type-C 和 12V 不要同时接。** 两路 5V 会顶在一起。
5. **PA11 也是 USB D-。** Type-C 接着电脑时，灯带控制会受影响。
6. **OLED 模块的引脚顺序**要和 J5 丝印（GND 3V3 SCL SDA）一致，不一致就用杜邦线交叉接。
7. **保险丝**：FH1 装 T2A 5×20 保险丝。
8. **第一次上电**先不插开发板，用万用表量 J13 的 5V 脚，确认是 5.0V 左右再插。
